# PromptFloat 1.2.0

Windows x64 便携版，自带 .NET 10 运行环境。解压 ZIP 运行 PromptFloat.exe；无需单独安装 .NET。

## 本版功能

- 新增四步首次教学，介绍悬浮球、分层菜单、模板插入、选区保存、润色及快捷键，可选择初始分类。
- 教学为非模态；显示前持久记录标记，仅自动显示一次。已有初始化数据的用户升级不弹出，设置 → 关于可回看。
- 保留常驻插入、三个自定义风格、一键保存配置、最新配置重试、拖动跟随气泡及安全替换。
- 公开源码、MIT 许可、依赖锁文件及 Windows 自动构建。

## 下载与升级

下载 PromptFloat-1.2.0-win-x64.zip 和对应 .sha256 校验文件。退出旧版再运行新版；已有模板和密钥继续使用。当前为便携交付，没有独立安装器，程序未做代码签名。

## 验证范围

80 项核心 / 模拟 API 检查和 132 项桌面检查通过；四页教学已逐页渲染检查。Edge 154.0.4258.37、记事本 10.0.26100.8875 与 VS Code 1.139.1 的专用输入回归通过。API 检查没有调用真实付费接口。

Chrome、Microsoft Word、微信/QQ、实际 AI 网页富文本、多屏混合 DPI、中文输入法组合和 Windows 10 待单独验证。自动替换取决于控件的 UI Automation 与权限，失败时提供复制，不自动重复粘贴。
